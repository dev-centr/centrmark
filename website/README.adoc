= CentrMark website (SolidStart)
:toc: macro

The `website/` workspace hosts the CentrMark documentation site, example registry, and themed diagram assets.

toc::[]

== Features

* **Documentation browser** — renders AsciiDoc sources from `public/docs/` (spec overview, informal spec, changelog, licensing).
* **Example registry** — syncs canonical `.cmk` files from `../examples/` and exposes rendered HTML plus canonical AST JSON.
* **Adaptive themed diagrams** — Mermaid sources with Themed SVG v1 manifests; see link:public/docs/adaptive-themed-diagrams.adoc[Adaptive themed website diagrams].

== Getting started

From the repository root (requires `pnpm`):

[source,bash]
----
pnpm install
pnpm --dir website dev
----

The dev script syncs examples, then starts the SolidStart app with Vinxi.

== Build and CI checks

[source,bash]
----
pnpm --dir website build
----

The build pipeline:

. Builds `@centrmark/cmk-renderer`
. Verifies themed diagram freshness (`diagrams:check`)
. Syncs examples into `public/examples/`
. Produces the production SolidStart bundle

Regenerate diagram SVGs after editing Mermaid sources:

[source,bash]
----
pnpm --dir website diagrams:generate
----

== Key directories

[cols="2,3",options="header"]
|===
| Path | Purpose
| `public/docs/` | AsciiDoc documentation served at `/docs/*`
| `public/examples/` | Synced CMK examples (generated; do not edit directly)
| `public/images/` | Generated themed SVG outputs
| `diagrams/` | Mermaid sources and theme manifests
| `scripts/` | Example sync and diagram generation
|===
